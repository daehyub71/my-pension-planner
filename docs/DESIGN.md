# DESIGN.md — my-pension-planner

> ✅ **상태: v1.0 합의** (2026-09-09). 시안은 [Claude Design 캔버스](https://claude.ai/code/artifact/7e117f3d-2689-4d26-b2dd-3595cb8aa0ec) **v2**(2026-09-09 재발행, P-8 반영)에 있다.
> 화면 구현(M3·M4)은 아래 §4 합의 기록에 해당 화면이 "합의"로 적힌 뒤에만 시작한다.
> 시안을 바꿀 때는 캔버스 수정 → 합의 → 이 문서 갱신 순서를 지킨다.

## 1. 정보 구조 (IA)

상단 탭 6개. 순서가 곧 사용자의 흐름이다: **질문 → 진단 → 비교 → 세부 → 데이터 → 근거**.

```
/            1 목표      "은퇴 후 매달 얼마를 쓰고 싶으세요?" + 소득이 끊기는 나이 → 필요·보유·갭
/dashboard   2 대시보드   연령별 3층 수령액 · 명목/실질 · 세전/가처분 · 절벽/크레바스 · 가정 슬라이더
/scenarios   3 시나리오   A/B/C 나란히 · 지표표 · 편집 패널
/disposable  4 가처분     한 해 해부 (세전 → 원천징수 → 5월 정산 → 건보료 → 가처분) · 1,500만 게이지
/data        5 데이터     엑셀·PDF 드롭 · 검증 결과 · 추가 입력 · 스냅샷
/rules       6 규칙 근거  검증 리포트 (등급 뱃지) · 연금 법규 라이브러리
```

- 데이터가 없으면 어느 탭이든 **데모 K씨**로 채우고 상단에 "데모 모드" 뱃지 (F19).
- 하단 상시 문구: "데이터는 이 브라우저를 떠나지 않습니다 · 세제 단순화 모델 · 투자 권유 아님" (N5).
- 화면 간 이동: 1→2 "갭 메우는 방법 보기" · 1→5 "내 연금 데이터 불러오기" · 2→3 "시나리오로 저장" · 4→6 "근거는 규칙 근거 페이지에서".

변경 이력
- 2026-09-09 v1 → v2: 1번에 「소득이 끊기는 나이」 필수 입력, 필요 금융자산 기준 시점을 "55세"에서 "은퇴 나이"로, 2번 크레바스 라벨을 "은퇴 60세 ~ 64세"로. 사유: SPEC D3·F7 — 크레바스는 은퇴 나이 없이 정의되지 않는다.
- 2026-09-13 2번 대시보드: 차트·툴팁·KPI 금액을 **연간 → 월 환산(÷12)**, 기본 토글을 **명목 → 실질**, 제목 「연령별 월 연금 수령액」, KPI 「최대 월 수령 (실질/명목[ 가처분], N세)」. 사유: 사용자 요청 — 연 단위는 체감이 어렵다. 개시 첫해는 부분 개월이라 월 환산이 실제 월액보다 작게 보인다(툴팁에 「월 환산」 표기).
- 2026-09-13 5번 데이터: 추가 입력 폼에 **원천 구성(계좌별)·국민연금 과세대상 비율** 칸을 넣기로 결정(사용자). **시안 수정 없이 기존 폼 양식으로 구현**하고 화면으로 확인받는다(사용자 결정 2026-09-13).
- 2026-09-13 합의 기록 정정: 3~6번이 「합의 대기」로 남아 있었으나 2026-09-09에 6장 모두 합의했다(SPEC·PLAN·CLAUDE.md 기록, 사용자 재확인).
- 2026-09-13 M4 구현 편차(시안 1·3·4번): 가처분 「수령 기간 N년」·「연기 시 N세 탈락」 문구는 엔진 역산으로 복원(20년 안에 경계를 못 넘기면 문구 없음) · 1,500만 게이지는 단색(여유 초록/초과 빨강) · 1,500만·5월 정산 카드는 명목 고정 · 가처분에 나이 선택·명목/실질 토글 추가(기본 실질) · 시나리오 칩은 체크 토글+이름 버튼, 비교는 최대 3개(표 포함) · 편집 패널에 월 지출·주택연금 입력 추가 · 목표 화면 기대수명은 가정 요약 줄에 표시만.
- 2026-09-13 M5 구현 편차(시안 6·2·3번): 규칙 근거는 검증 리포트/법규 라이브러리를 토글로 한 번에 하나만 보여 준다 · 요약 카드는 규칙 수(N/M) 기준, 그룹 수는 보조 문구 · 규칙표는 그룹 머리행이 있는 표 · 법제처 검색은 라이브러리 카드 위(키 없으면 법제처 링크만) · 데모 뱃지는 모든 화면 머리 오른쪽 · 데이터 화면에 「추가 입력 저장」 버튼과 스냅샷 비교 상자 추가.
